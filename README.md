# Num - BaseBall - Request

## 기능 요구 사항

---

1. 플레이어 입력 / 컴퓨터 숫자 출력
    - User 도메인 기능 \
        현재 입력받은 숫자 검증 (O)
        
    - Computer 도메인 기능 \
        게임 시작 시 Random 숫자 부여

2. 컴퓨터 숫자 부여

3. 스트라이크, 볼 판단 (힌트)
    - 위치까지 동일하면 Strike
    - 값만 존재하면 ball

4. View
    - Input
      - 숫자가 3개인지 판단
    - Result
      - 현재 볼카운트 출력
      - 숫자 모두 맞힌 경우 게임 종료 문구 출력
      - 볼 스트라이크 중 하나라도 0개라면 출력되지 않아야 함.
   
5. 게임 종료 후 restart or finish
